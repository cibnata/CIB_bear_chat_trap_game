# CIB_bear_chat_trap_game

**刑事Bear：聊天陷阱搜查線** 是一款以「聊天情境」設計的防詐互動遊戲。玩家會在每一關看到 A、B 兩段看起來都像真的對話，必須把兩邊訊息看完，再判斷每一段是真的，還是暗藏詐騙陷阱。

## 遊戲特色

- 每次遊戲隨機抽出 5 個關卡
- 同一詐騙案類具備多組對話，會隨機出現
- A／B 對話真假順序會隨機調換
- 玩家可選擇男玩家或女玩家頭像
- 輸入暱稱後需按 Enter 確認，再按「開始遊戲」
- 交友情境會依玩家頭像切換男網友／女網友角色
- 不同角色使用不同頭像與對話泡泡顏色
- 對話會一則一則展開，並提示玩家按「繼續對話」
- 對話增加時，畫面會自動滑動，讓「繼續對話」按鈕維持可見
- 支援手機、平板與桌機 RWD 顯示
- 純 HTML / CSS / JavaScript，不需後端即可執行

## 遊戲說明

玩家進入遊戲後，先選擇玩家頭像並輸入暱稱。  
按 Enter 確認暱稱後，再按「開始遊戲」。

每一關會出現一段故事開場，接著有「對話 A」與「對話 B」。  
請先按「繼續對話」把兩邊訊息都看完，再判斷每段對話：

- 這是真的
- 這是詐騙

系統會在作答後顯示正解、詐騙警訊與安全提醒。

## 如何使用

直接用瀏覽器開啟 `index.html` 即可遊玩。

## 部署到 GitHub Pages

1. 建立新的 GitHub Repository，例如：`CIB_bear_chat_trap_game`
2. 將 `index.html` 與 `README.md` 上傳到 Repository 根目錄
3. 進入 Repository 的 **Settings**
4. 點選 **Pages**
5. Source 選擇 **Deploy from a branch**
6. Branch 選擇 `main`，資料夾選擇 `/root`
7. 儲存後等待 GitHub Pages 產生網址

## 本機測試

可直接雙擊 `index.html` 開啟。  
也可以使用 VS Code 的 Live Server 預覽。

## 專案定位

本遊戲適合作為防詐宣導、校園教育、社群推廣、警政宣導活動或互動式教材使用。透過聊天對話情境，讓民眾練習辨識詐騙話術，提高防詐警覺。
